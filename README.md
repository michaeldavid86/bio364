# BIO 364 — Course Companion

An interactive companion site for **BIO 364, Molecular Biology Methods**
(USAFA, Fall 2026): lessons and objectives, the Trivium readings, the notebook
rubric, practice tools, and a set of molecular explorables.

**Live site:** https://michaeldavid86.github.io/bio364/

## About this repository

This repository holds the published site and nothing else — a single
self-contained HTML file. It makes no network requests, sets no cookies,
collects no data, and has no backend. Cadet progress is stored in the cadet's
own browser and is never transmitted anywhere.

The build scripts and course data that generate this file are maintained
separately and are not published here.

## Authority of record

**Blackboard is authoritative.** Where this site and Blackboard disagree,
Blackboard is correct. Schedule and assignments are subject to change at the
course director's discretion based on experimental progress and kit
availability.

The footer carries a `version YYYY-MM-DD` stamp so a stale copy is
identifiable at a glance.

## Reporting a problem

Errors in the site — a wrong date, a broken tool, a claim that does not read
right — should go to the course director directly rather than through this
repository.
